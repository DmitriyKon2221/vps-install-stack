# VPS install stack

Установщик для **чистого Ubuntu 24.04 VPS, x86_64**. Разворачивает AmneziaWG 3 с приватной панелью AWG-Easy 3, Hysteria2 и обычную HTTP-страницу. Готовые профили и пароли создаются на самом сервере и появляются в `/root/vps-access` после успешных проверок.

Это новый сервер с новыми ключами. Установщик не переносит старые профили, не восстанавливает старый IP и отказывает при обнаружении существующей установки. На действующем сервере его запускать нельзя.

## Установка

Подключитесь по SSH к новому VPS и выполните:

```bash
sudo apt-get update
sudo apt-get install -y git curl
git clone https://github.com/DmitriyKon2221/vps-install-stack.git
cd vps-install-stack
sudo bash install.sh
```

Для воспроизводимости после публикации релиза можно переключиться на его тег перед запуском: `git checkout v1.0.0`. Проверяйте тег и содержимое скрипта до запуска от root. Не используйте `curl | bash` с изменяемой веткой `main`.

По умолчанию AWG слушает **UDP/443**, Hysteria2 — **UDP/8443**, приватная панель — `http://10.8.0.1:51821/` только из VPN, статус-страница — **TCP/80**. У провайдера должны быть разрешены эти порты и SSH TCP/22. Если у VPS внешний firewall, установщик не сможет изменить его автоматически.

Параметры:

```bash
sudo bash install.sh --host 203.0.113.10 --awg-port 443 --hysteria-port 8443 --users 5
sudo bash install.sh --no-web
```

`--host` нужен, если публичный IPv4 не определяется автоматически. Без `--no-web` порт TCP/80 должен быть свободен. Скрипт не изменяет SSH-конфигурацию и не отключает парольный вход.

## После установки

```bash
sudo ls -la /root/vps-access
sudo cat /root/vps-access/panel.txt
sudo cat /root/vps-access/awg-admin.txt
sudo cat /root/vps-access/hysteria-primary.txt
```

Файлы:

| Файл | Назначение |
| --- | --- |
| `panel.txt` | адрес и пароль приватной панели |
| `awg-admin.txt` | первый Home профиль `vpn://` для AmneziaVPN |
| `hysteria-primary.txt` | основной профиль Hysteria2 для HAPP |
| `hysteria-users.txt` | отдельные Hysteria2 профили для устройств |
| `server.txt` | адрес сервера и порты без паролей |

Для сервера, установленного до исправления раздельного туннелирования, обновите репозиторий и создайте совместимый профиль с теми же ключами:

```bash
cd ~/vps-install-stack
git pull --ff-only
python3 fix-amnezia-profile.py /root/vps-access/awg-admin.txt /root/vps-access/awg-admin-split.txt
```

Отключите VPN в AmneziaVPN, импортируйте новый `awg-admin-split.txt` и проверьте раздельное туннелирование сайтов. После успешной проверки удалите старую запись подключения из приложения. На сервере VPN, панель и ключи не меняются. Профили `vpn://`, экспортированные самой панелью AWG-Easy 3, также нужно пропустить через `fix-amnezia-profile.py` перед импортом в AmneziaVPN. Файлы `.conf` для AmneziaWG этой правки не требуют.

Скопировать папку на свой ПК можно по SFTP или `scp -r root@IP:/root/vps-access ./`. Не выкладывайте эти файлы в GitHub, облачный общий доступ или чат. Для выдачи друзьям передавайте только один нужный профиль. У Hysteria2 пользователи независимы, а пароль Salamander общий для сервера; при отзыве пользователя удалите его из `/etc/hysteria/config.yaml` и перезапустите `hysteria-server`.

Панель AWG-Easy доступна после подключения первого Home профиля. В ней можно создавать новые Home и Guest профили. Порт панели не открыт в публичном интернете.

## Проверка и обслуживание

```bash
sudo awg-easy-3 status
sudo systemctl status hysteria-server.service
sudo systemctl status vps-stack-firewall.service
sudo ss -lunp
```

AWG-Easy берётся из закреплённого Git-коммита `930dc6021024db9c8bbda7d92944aa9fef7baf3c` и образа 0.1.6 с закреплённым Docker digest. Hysteria2 берётся из официального релиза v2.13.0, проверяется закреплённым SHA-256. Автоматическое обновление AWG отключено: обновляйте после резервной копии и проверки совместимости. Конфигурации Hysteria включают `disablePathMTUDiscovery`, а служба — отключение QUIC GSO/ECN, так как это помогло на проверенном VPS.

Сертификат Hysteria2 самоподписанный. Ссылка содержит его SHA-256 и `insecure=1`, что требуется некоторым клиентам для такого сертификата. Клиентам, которые игнорируют `pinSHA256`, эта ссылка не даёт строгой проверки подлинности сервера. Для публичного использования лучше настроить собственный домен и сертификат доверенного УЦ.

## Безопасность репозитория

В репозитории нет SSH-паролей, VPN-ключей, SFTP-файлов, адресов действующих серверов и готовых клиентских профилей. Секреты генерируются криптографическим генератором на VPS, записываются в файлы root с правами `0600`; каталог доступа имеет права `0700`. `.gitignore` блокирует типичные конфиденциальные расширения, но перед каждым коммитом всё равно проверяйте `git diff --cached`.

Пароли и исходный профиль AWG временно содержатся в `/root/.vps-install-stack-stage`, доступном только root. После успешной проверки создаётся `/root/vps-access`. Если установка прервётся, этот закрытый временный каталог остаётся для диагностики; не запускайте установщик повторно на частично настроенном VPS без анализа состояния.

При внешней блокировке IP новый сервер получит новые ключи и ссылки, но сам публичный IP всё равно может быть обнаружен по сетевым признакам. Протоколы и страница статуса не дают гарантии от блокировки.

## Состав и источники

- [AWG-Easy 3](https://github.com/alexsemenovru/awg-easy-3) — веб-панель и AmneziaWG 3.
- [Hysteria2](https://hysteria.network/docs/getting-started/Server/) — отдельный UDP протокол.
- [Hysteria2: учётные записи](https://hysteria.network/docs/advanced/Full-Server-Config/) — режим `userpass`.

Лицензии сторонних компонентов находятся в их репозиториях. Этот репозиторий содержит только установщик и шаблон страницы.
